# fractal-zeta
フラクタル現象の研究
# Project Title

フラクタル構造の数理的研究。
経路構造に自然に現れるフラクタル構造をトレース束として研究。
融合代数からフラクタル非閉包代数の構造を構築し、準連結構造、ゼータ幾何などを行う。
数値計算をして概念探索してから、理論化している。

## Author

Hiroki Honda

Independent Researcher

- Dynamical Transformation Theory

## Research Vision

本研究は、

- フラクタル構造
- 非閉包代数
- 準連結性
- 散逸構造
- ゼータ関数

を統一的に記述する数理体系の構築を目的とする。

特に、

「局所的な忘却・散逸から、
どのように大域的な秩序や数論的構造が創発するか」

を中心課題としている。

本研究は既存理論の整理ではなく、
新しい数学的構造の提案を目的とする。
