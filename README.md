## Overview

このリポジトリは、現在進行中の理論研究・数式実験・論文草稿をまとめたものです。

主なテーマ：

- フラクタル構造
- ゼータ関数
- トレース束
- 準連結性
- 動的変容理論
- 非可換構造
- 干渉・散逸・スペクトル構造

など。

内容は発展途中であり、将来的に大きく変更される可能性があります。
